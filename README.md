# Nan Zhang — Personal Academic Website

Source code for [zhangnanpku.github.io](https://zhangnanpku.github.io), built with
[Jekyll](https://jekyllrb.com/) and the
[al-folio](https://github.com/alshedivat/al-folio) theme.

The website includes a biography, publications, teaching materials, and group
information. It uses shared typography, responsive tables, and publication
links to journal articles, arXiv preprints, and source code.
